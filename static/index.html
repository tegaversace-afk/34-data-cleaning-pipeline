How it works

  1. Ingest (ingest.py) reads the CSV safely and rejects empty/oversized/non-CSV files.
  2. Validate (validate.py) checks emails, ages, phones, dates and missing values.
  3. Transform (transform.py) trims spaces, fixes casing, standardises dates, removes duplicates.
  4. Report + Storage (report.py, database.py) builds statistics and saves the run in SQLite.
  5. API + UI (main.py, static/) — FastAPI endpoints, this dashboard, Render deployment.
